怎麼算的。每檔股票取最近 個交易日的開高低收量，交給 Kronos-small 一根一根往後生成 20 根 K 線，重複 次得到 條可能的走勢。上漲機率是其中 20 日後收盤高於今天的比例，藍色區域是 10% 到 90% 分位。股價來自 FinMind 台股日成交資訊（失敗時改用 Yahoo 財經），每個交易日 16:17 由 GitHub 雲端主機自動重跑，不需要開電腦。
回測怎麼做。假裝站在 20、40、60、80、100、120 個交易日前，只用當時看得到的資料做同樣的預報，再跟後來實際的收盤比。區間如果做得好，實際價格應該大約 80% 的時間落在藍色區域裡。
實測下來的問題。Kronos 在日線上對漲幅很大的股票會明顯偏空，回看期拉長到 400 日時，景碩被預測 20 日跌 70%，實際只跌 22%，因此這裡改用 120 日回看。它的訓練資料以分鐘線為主，日線準度沒有論文圖表那麼好，請把這頁當成股智通之外的第二意見，不要直接當成買賣訊號。這不是投資建議。
